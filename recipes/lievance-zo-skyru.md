---
title: Lievance zo skyru
description: Nadýchané lievance zo skyru a vajec, hotové za chvíľu.
tags: [raňajky, rýchlovka]
ingredients:
  - items:
      - { qty: 2, unit: balenie, item: skyr }
      - { qty: 2, unit: ks, item: vajce }
      - { qty: 3, unit: lyžica, item: múka, note: vrchovaté }
      - { item: cukor, note: od oka }
      - { item: kypriaci prášok }
      - { item: voda, note: trochu }
---

1. Skyr, vajíčka, múku, cukor a kypriaci prášok zmiešame a pridáme trochu vody. Cesto má mať hustotu ako krémový grécky jogurt.
2. Lievance opekáme na panvici.
