---
title: Teplý šalát s hráškom a fazuľkami
description: Rýchly teplý šalát z hrášku a fazuliek na masle s jarnou cibuľkou, fetou a semienkami.
tags: [šalát, vegetariánske, rýchlovka]
ingredients:
  - items:
      - { item: mrazený hrášok }
      - { item: mrazené fazuľky }
      - { item: soľ }
      - { item: maslo }
      - { item: jarná cibuľka }
      - { item: feta }
      - { item: tekvicové semienka }
---

1. Hrášok a fazuľky uvaríme v osolenej vode.
2. Na masle jemne opečieme jarnú cibuľku.
3. Pridáme hrášok a fazuľky a obalíme ich v masle.
4. Na tanieri posypeme fetou a tekvicovými semienkami.
