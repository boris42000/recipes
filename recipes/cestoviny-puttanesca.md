---
title: Cestoviny puttanesca
description: Výrazná talianska klasika s ančovičkami, kaparami, chilli a rajčinami.
tags: [cestoviny, ryby, hlavné jedlo]
ingredients:
  - items:
      - { item: cestoviny }
      - { item: cibuľa, note: viac }
      - { item: cesnak, note: viac }
      - { item: ančovičky }
      - { item: kapary }
      - { item: chilli }
      - { item: víno }
      - { qty: 1, unit: plechovka, item: rajčiny }
      - { item: petržlenová vňať }
      - { item: čierne korenie }
      - { item: soľ }
      - { item: olej }
---

1. Uvaríme cestoviny a odložíme si vodu z cestovín.
2. Na olej dáme viac nasekanej cibule, potom pridáme viac cesnaku.
3. Pridáme nakrájané ančovičky, nakrájané kapary a chilli.
4. Podlejeme vínom a necháme odpariť.
5. Pridáme rajčiny z plechovky a zredukujeme.
6. Pridáme petržlenovú vňať a čierne korenie.
7. Prilejeme vodu z cestovín a necháme zredukovať.
8. Dochutíme soľou a korením a premiešame s cestovinami.
