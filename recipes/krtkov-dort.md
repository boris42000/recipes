---
title: Krtkov dort
description: Kakaový korpus s banánmi a jahodami pod kopcom šľahačkovo-mascarpone krému.
cookTime: 70
tags: [dezert, pečenie]
ingredients:
  - group: Korpus
    items:
      - { qty: 350, unit: g, item: hladká múka }
      - { qty: 50, unit: g, item: kakao }
      - { qty: 1, unit: lyžička, item: prášok do pečiva, note: kopcovitá }
      - { qty: 130, unit: g, item: maslo, note: izbová teplota }
      - { qty: 200, unit: g, item: cukor, note: pol hnedý a pol kryštálový }
      - { qty: 2, unit: ks, item: vajce }
      - { qty: 115, unit: ml, item: rozpustené maslo, note: alebo rastlinný olej }
      - { qty: 350, unit: ml, item: mlieko, note: teplé alebo izbovej teploty }
  - group: Krém
    items:
      - { qty: 2, unit: balenie, item: smotana na šľahanie }
      - { qty: 2, unit: balenie, item: mascarpone }
      - { qty: 0.5, unit: balenie, item: hrudkovitý tvaroh }
      - { qty: 2.5, unit: ks, item: banány, note: 2–3 ks }
      - { qty: 1, unit: ks, item: horká čokoláda }
      - { qty: 2, unit: balenie, item: vanilkový cukor }
      - { qty: 1.5, unit: lyžica, item: cukor, note: veľké }
  - group: Plnka
    items:
      - { item: banány }
      - { item: jahody }
---

1. V jednej mise zmiešame múku, kakao a prášok do pečiva.
2. V druhej mise mixujeme maslo s cukrom asi 5 minút.
3. Pridáme vajíčka a necháme ich spojiť. Potom pridáme rozpustené maslo (alebo olej) a nakoniec mlieko.
4. Suchú zmes postupne zamiešavame do mokrej.
5. Boky formy vymastíme a na dno dáme papier na pečenie. Rúru rozohrejeme na 180 °C, teplovzduch.
6. Pečieme 50–60 minút, kým nie je špajdľa čistá, a potom ešte asi 10–15 minút navyše.
7. Korpus necháme vychladnúť cez noc.
8. Na krém vyšľaháme smotany, pridáme mascarpone, tvaroh, popučené banány a nasekanú čokoládu. Dosladíme vanilkovým cukrom a cukrom.
9. Z korpusu odrežeme vrch a vydlabeme ho asi 2–3 cm do hĺbky.
10. Do jamky poukladáme pozdĺžne prekrojené banány a jahody, navrch dáme krém a vytvarujeme kopec.
11. Kopec posypeme vydlabaným korpusom.
