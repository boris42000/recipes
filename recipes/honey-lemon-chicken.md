---
title: Honey lemon chicken
description: Kuracie prsia v citrónovo-medovej marináde, pečené v rúre, s omáčkou z fety a gréckeho jogurtu.
tags: [kuracie, hlavné jedlo]
ingredients:
  - group: Kura
    items:
      - { item: kuracie prsia }
      - { qty: 1, unit: ks, item: citrón }
      - { qty: 1, unit: lyžica, item: med, note: veľká }
      - { item: mletá červená paprika, note: trochu }
      - { item: oregano }
      - { item: olivový olej }
  - group: Omáčka
    items:
      - { item: feta }
      - { item: grécky jogurt }
      - { item: med }
---

1. Kuracie prsia nakrájame a dáme do marinády z citróna, medu, červenej papriky, oregana a olivového oleja.
2. Kura upečieme v rúre.
3. Fetu, grécky jogurt a med vymixujeme na omáčku a podávame ku kuraťu.
