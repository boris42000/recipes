---
title: Tekvicové krupoto
description: Krémové krúpy s tekvicovým pyré, syrom a chrumkavými orieškami a semienkami.
tags: [hlavné jedlo, vegetariánske]
ingredients:
  - items:
      - { item: šalotka }
      - { item: krúpy }
      - { item: víno }
      - { item: vývar }
      - { item: tekvicové pyré }
      - { item: maslo, note: trochu }
      - { item: syr Vršatec }
      - { item: lieskové orechy }
      - { item: tekvicové semienka }
---

1. Šalotku opečieme do sklovita.
2. Pridáme krúpy a opečieme ich do sklovita.
3. Podlejeme vínom a necháme odpariť.
4. Pridávame vývar a tekvicové pyré a varíme, kým krúpy nezmäknú.
5. Primiešame trochu masla a syr Vršatec.
6. Navrch posypeme lieskovými orechmi a tekvicovými semienkami.

## Poznámky
- Dá sa spraviť aj s cviklou namiesto tekvice.
