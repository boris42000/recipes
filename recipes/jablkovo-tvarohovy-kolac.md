---
title: Jablkovo-tvarohový koláč
description: Krehký koláč s tvarohovou plnkou a karamelizovanými plátkami jabĺk so škoricou.
cookTime: 65
tags: [dezert, pečenie]
ingredients:
  - group: Cesto
    items:
      - { qty: 220, unit: g, item: hladká múka }
      - { qty: 120, unit: g, item: maslo, note: studené }
      - { qty: 65, unit: g, item: kryštálový cukor }
      - { qty: 1, unit: štipka, item: soľ }
      - { qty: 3, unit: lyžica, item: voda, note: veľmi studená }
  - group: Plnka
    items:
      - { qty: 500, unit: g, item: hladký tvaroh }
      - { qty: 5, unit: lyžica, item: cukor }
      - { qty: 20, unit: g, item: vanilkový cukor }
      - { qty: 1, unit: ks, item: žĺtok }
      - { qty: 3, unit: lyžica, item: mlieko, note: asi }
      - { item: grécky jogurt }
  - group: Navrch
    items:
      - { qty: 3, unit: ks, item: jablko, note: nakrájané natenko }
      - { qty: 70, unit: g, item: maslo, note: rozpustené }
      - { item: škoricový cukor }
      - { qty: 2, unit: lyžica, item: cukor, note: na karamelizovanie }
---

1. Zmiešame múku s cukrom a soľou a pridáme studené maslo. Rozmrvíme ho, kým zmes nie je ako mokrý piesok.
2. Pridáme studenú vodu, vytvarujeme kruh a dáme do chladničky aspoň na 30 minút.
3. Všetky suroviny na plnku spolu zmiešame.
4. Okrúhlu formu na pečenie vymastíme a vysypeme. Cesto vyvaľkáme asi na pol centimetra, vložíme do formy a vytvoríme okraje.
5. Nalejeme tvarohovú plnku a navrch do kruhu ukladáme plátky jabĺk.
6. Jablká polejeme rozpusteným maslom a posypeme škoricovým cukrom a ešte cukrom, aby skaramelizovali.
7. Pečieme v teplovzdušnej rúre na 180 °C 55 minút, prípadne ešte 10 minút navyše.
