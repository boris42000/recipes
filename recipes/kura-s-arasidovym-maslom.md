  - items:
      - { item: kuracie mäso }
      - { item: cibuľa }
      - { qty: 4, unit: lyžica, item: arašidové maslo }
      - { qty: 5, unit: lyžica, item: sójová omáčka }
      - { item: kokosové mlieko }
      - { item: soľ }
---

1. Na cibuli opečieme mäso.
2. V miske zmiešame arašidové maslo, sójovú omáčku, kokosové mlieko a soľ.
3. Omáčku pridáme k mäsu a povaríme.
