---
title: Šošovicový prívarok
description: Krémová kyslastá šošovica so smotanou, octom a sušenými slivkami.
tags: [slovenské, hlavné jedlo, vegetariánske]
ingredients:
  - items:
      - { qty: 1, unit: ks, item: cibuľa, note: veľká }
      - { qty: 350, unit: g, item: šošovica, note: odmočená }
      - { qty: 2, unit: strúčik, item: cesnak, note: "väčšie, pretlačené" }
      - { qty: 2, unit: ks, item: bobkový list }
      - { qty: 3, unit: ks, item: sušené slivky }
      - { item: soľ }
      - { item: voda }
      - { qty: 1, unit: balenie, item: smotana na šľahanie }
      - { qty: 250, unit: ml, item: mlieko }
      - { qty: 2, unit: lyžica, item: hladká múka, note: 2–3 lyžice }
      - { qty: 4, unit: lyžica, item: ocot, note: 4–5 lyžíc }
---

1. K jednej veľkej cibuli pridáme odmočenú šošovicu, pretlačený cesnak, bobkové listy, sušené slivky a soľ.
2. Zalejeme vodou tak, aby bola asi 3–4 cm nad šošovicou.
3. Privedieme k varu a varíme asi 15 minút. Skontrolujeme, dolejeme vodu a varíme do mäkka.
4. Keď zostane trochu vody, pridáme smotanu a mlieko rozmiešané s múkou a necháme prejsť varom.
5. Stiahneme z ohňa, pridáme ocot a dosolíme.
