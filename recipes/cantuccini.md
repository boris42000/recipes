---
title: Cantuccini
description: Chrumkavé talianske mandľové sušienky s medom a citrusovou kôrou, dvakrát pečené.
tags: [dezert, pečenie]
ingredients:
  - group: Na 1 plech
    items:
      - { qty: 250, unit: g, item: hladká múka }
      - { qty: 1, unit: štipka, item: soľ }
      - { qty: 2, unit: lyžička, item: prášok do pečiva }
      - { qty: 2, unit: lyžica, item: med }
      - { qty: 1, unit: ks, item: citrón, note: kôra }
      - { item: pomaranč, note: kôra z časti pomaranča }
      - { qty: 80, unit: g, item: práškový cukor }
      - { qty: 170, unit: g, item: mandle }
      - { qty: 2, unit: ks, item: vajce }
  - group: Voliteľne
    items:
      - { item: sušené hrozienka, note: alebo brusnice či kandizovaný pomaranč }
---

1. Suché suroviny premiešame s mandľami, pridáme med a vajcia.
2. Vareškou vymiešame súvislé cesto, vyklopíme ho na dosku a rozdelíme na dve alebo tri časti.
3. Z každej časti vyvaľkáme hranol a uložíme na papier na pečenie.
4. Pečieme vo vyhriatej rúre na 180 °C 25–30 minút.
5. Keď je cesto upečené, ale ešte nie hnedé, vyberieme ho a zúbkovaným nožíkom nakrájame na plátky.
6. Plátky poukladáme na plech a sušíme na 130 °C 15 minút.
