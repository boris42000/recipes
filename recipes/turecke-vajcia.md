---
title: Turecké vajcia
description: Vajcia s tekutým žĺtkom na cesnakovom jogurte s maslom a údenou paprikou.
tags: [raňajky, vegetariánske, rýchlovka]
ingredients:
  - items:
      - { item: grécky jogurt }
      - { qty: 1, unit: strúčik, item: cesnak }
      - { item: kôpor, note: ak mám }
      - { item: soľ }
      - { item: maslo }
      - { item: údená paprika }
      - { item: vajcia }
      - { item: mandle, note: nasekané }
      - { item: tekvicové semienka }
---

1. Do gréckeho jogurtu pridáme strúčik cesnaku, kôpor (ak máme) a soľ.
2. Z masla a údenej papriky spravíme olej.
3. Pripravíme vajíčka tak, aby žĺtok zostal tekutý.
4. Vajíčka dáme na jogurt, polejeme paprikovým maslom a posypeme nasekanými mandľami a tekvicovými semienkami.
