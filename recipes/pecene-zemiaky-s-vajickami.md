title: Pečené zemiaky s vajíčkami a koprovým jogurtom
description: Chrumkavé zemiaky, volské oká s tekutým žĺtkom, koprový jogurt a slaninka.
tags: [raňajky, hlavné jedlo]
ingredients:
  - group: Základ
    items:
      - { item: zemiaky }
      - { item: vajcia }
      - { item: slanina }
  - group: Koprový jogurt
    items:
      - { item: skyr }
      - { item: kôpor, note: veľa }
      - { item: horčica }
      - { item: citrón }
      - { item: cesnak, note: možno }
---

1. Upečieme zemiaky do chrumkava.
2. Na koprový jogurt zmiešame skyr, veľa kôpru, horčicu, citrón a prípadne cesnak.
3. Slaninu opečieme do chrumkava a nasekáme na kocky.
4. Pripravíme vajíčka ako volské oká s tekutým žĺtkom.
5. Zemiaky podávame s vajíčkami, koprovým jogurtom a slaninou.
