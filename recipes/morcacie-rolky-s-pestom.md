---
title: Morčacie rolky s lučinou a pestom
description: Morčacie rolky plnené lučinou, pestom, sušenými rajčinami a zelenou fazuľkou, pečené v rúre.
tags: [mäso, hlavné jedlo]
ingredients:
  - items:
      - { item: morčacie mäso, note: plátky }
      - { item: lučina }
      - { item: pesto }
      - { item: sušené rajčiny }
      - { item: zelená fazuľka, note: do rolky aj na prílohu }
      - { item: kaša, note: na prílohu }
---

1. Morčacie plátky natrieme lučinou a pestom, pridáme sušené rajčiny a zelenú fazuľku a zrolujeme.
2. Pečieme v rúre na 190 °C.
3. Podávame so zelenou fazuľkou a kašou.
