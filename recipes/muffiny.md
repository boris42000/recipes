description: Kakaové muffiny s tvarohom a medom, plné čučoriedok a kúskov čokolády.
cookTime: 30
tags: [pečenie, dezert, raňajky]
ingredients:
  - group: Mokrá zmes
    items:
      - { qty: 2, unit: ks, item: vajce }
      - { qty: 250, unit: g, item: hladký tvaroh }
      - { qty: 3, unit: lyžica, item: med, note: veľké }
      - { qty: 80, unit: g, item: maslo, note: rozpustené }
      - { qty: 100, unit: ml, item: mlieko }
  - group: Suchá zmes
    items:
      - { qty: 215, unit: g, item: hladká pšeničná múka }
      - { qty: 1, unit: balenie, item: kypriaci prášok }
      - { qty: 2, unit: lyžica, item: kakao, note: kopcovité }
  - group: Do cesta
    items:
      - { qty: 2, unit: hrsť, item: čučoriedky }
      - { qty: 50, unit: g, item: čokoláda, note: nasekaná }
---

1. Zmiešame vajíčka s tvarohom a medom, pridáme rozpustené maslo a zamiešame.
2. V druhej miske zmiešame múku, kypriaci prášok a kakao.
3. Suchú zmes postupne pridávame do mokrej. Keď je cesto príliš tuhé, postupne prilievame mlieko, po troškách tak, ako pridávame múku.
4. Nakoniec vmiešame čučoriedky a nasekanú čokoládu.
5. Pečieme vo fritéze na 160 °C asi 30 minút.

## Poznámky
- V rúre by sa piekli asi na 175 °C 25–30 minút.
- Nabudúce by som možno dala o 1 lyžicu medu viac.
