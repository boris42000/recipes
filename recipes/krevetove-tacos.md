---
title: Krevetové tacos
description: Opečené krevety v arašidovo-limetkovej omáčke s mangom, avokádom a mrkvou.
tags: [tacos, ryby, rýchlovka]
ingredients:
  - group: Tacos
    items:
      - { item: krevety }
      - { item: tortilly }
      - { item: mango }
      - { item: avokádo }
      - { item: mrkva }
  - group: Omáčka
    items:
      - { item: arašidové maslo }
      - { item: limetka }
      - { item: med }
      - { item: koriander }
---

1. Krevety opečieme.
2. Zmiešame omáčku z arašidového masla, limetky, medu a koriandra a krevety ňou potrieme.
3. Tacos naplníme krevetami a pridáme mango, avokádo a mrkvu.
