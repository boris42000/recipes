title: Jednoduchý liaty koláč s ovocím
description: Rýchly koláč na plech s kyslou smotanou, citrónovou kôrou a hrsťami mrazeného alebo čerstvého ovocia.
cookTime: 35
tags: [dezert, pečenie]
source: Karolina Four
ingredients:
  - group: Na pekáč 20 × 32 cm
    items:
      - { qty: 100, unit: g, item: krupicový cukor, note: môže byť trstinový }
      - { qty: 100, unit: g, item: maslo, note: "mäkké, plus kúsok na vymazanie formy" }
      - { qty: 2, unit: ks, item: vajce, note: stredne veľké }
      - { qty: 1, unit: ks, item: citrón, note: "kôra, chemicky neošetrený" }
      - { qty: 2, unit: lyžička, item: vanilkový extrakt }
      - { qty: 4, unit: lyžica, item: mlieko }
      - { qty: 200, unit: g, item: kyslá smotana, note: 15 % }
      - { qty: 200, unit: g, item: hladká múka, note: 1/3 až 1/2 sa dá nahradiť jačmennou celozrnnou }
      - { qty: 9, unit: g, item: kypriaci prášok, note: 1 vrchovatá lyžička }
      - { qty: 1, unit: štipka, item: soľ }
      - { qty: 2, unit: hrsť, item: ovocie, note: mrazené alebo čerstvé }
      - { item: práškový cukor, note: na posypanie }
---

1. Suroviny vyberieme z chladničky 30 minút pred pečením. Rúru predhrejeme na 200 °C a pekáč vymažeme maslom.
2. Krupicový cukor vyšľaháme s maslom do krému. Postupne po jednom dôkladne zašľaháme obe vajcia.
3. Všľaháme citrónovú kôru, vanilkový extrakt, mlieko a nakoniec kyslú smotanu.
4. V miske zmiešame preosiatu múku, kypriaci prášok a štipku soli. Opatrne ju pridáme k mokrej zmesi a šľaháme len krátko, kým sa nespojí do hladkého cesta. Cesto preložíme do pekáča.
5. Na cesto rovnomerne rozložíme ovocie. Mrazené vopred nerozmrazujeme.
6. Vložíme do rúry, znížime teplotu na 180 °C a pečieme asi 35 minút, kým povrch nezozlatne a špajdľa nevyjde čistá.
7. Ešte vlažný koláč môžeme posypať práškovým cukrom.
