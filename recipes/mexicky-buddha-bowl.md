---
title: Buddha bowl na mexický spôsob
description: Miska s quinoou, kuracím mäsom s fajitas korením, avokádom, kukuricou a fazuľou.
tags: [kuracie, hlavné jedlo]
ingredients:
  - items:
      - { item: quinoa }
      - { item: kuracie mäso }
      - { item: paprika }
      - { item: cibuľa }
      - { item: fajitas korenie }
      - { item: čerstvý koriander }
      - { item: kukurica }
      - { item: avokádo }
      - { item: fazuľa }
      - { item: semienka, note: nejaké }
---

1. Uvaríme quinou.
2. Kuracie mäso upečieme s paprikou a cibuľou a s fajitas korením.
3. Do misky dáme quinou, mäso so zeleninou, kukuricu, fazuľu a avokádo.
4. Posypeme koriandrom a semienkami.
