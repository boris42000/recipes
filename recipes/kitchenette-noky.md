---
title: Kitchenette noky
description: Opečené noky so slaninou, balzamikovou cibuľou, cherry rajčinami a zelerom.
tags: [hlavné jedlo]
source: Kitchenette
ingredients:
  - items:
      - { qty: 150, unit: g, item: slanina }
      - { item: olej }
      - { qty: 6, unit: ks, item: cibuľa, note: na štvrtky }
      - { qty: 4, unit: lyžica, item: hustý balzamikový ocot, note: 4–5 lyžíc }
      - { qty: 250, unit: g, item: cherry rajčiny }
      - { qty: 4, unit: ks, item: rapíkatý zeler, note: 4–5 stoniek }
      - { qty: 1, unit: kg, item: uvarené noky }
      - { item: soľ }
      - { item: korenie }
---

1. Osmažíme slaninu.
2. Na olej dáme cibule nakrájané na štvrtky.
3. Pridáme balzamiko, cherry rajčiny a rapíkatý zeler.
4. Zmiešame slaninu so zeleninou, dosolíme a dokoreníme.
5. Na ďalšej panvici na oleji osmažíme uvarené noky.
6. Noky pridáme k zmesi.
