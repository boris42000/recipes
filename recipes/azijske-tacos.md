---
title: Ázijské tacos
description: Malé mäsové placky so zázvorom, sójovkou, mrkvou a kapustou, s koriandrom a limetkou.
tags: [tacos, ázijské, mäso, hlavné jedlo]
ingredients:
  - group: Mäsová zmes
    items:
      - { qty: 500, unit: g, item: mleté mäso, note: zmes hovädzieho a bravčového }
      - { qty: 1, unit: ks, item: mrkva, note: nahrubo nastrúhaná }
      - { item: biela kapusta, note: asi 1/4 hlávky nadrobno }
      - { qty: 1, unit: lyžica, item: med }
      - { qty: 1, unit: lyžica, item: ryžový ocot }
      - { qty: 2, unit: lyžica, item: sójová omáčka }
      - { item: zázvor, note: väčší kúsok nastrúhaný }
      - { qty: 1, unit: strúčik, item: cesnak, note: 1–2 strúčiky }
      - { item: soľ }
  - group: Na podávanie
    items:
      - { item: malé placky }
      - { item: čerstvá mrkva }
      - { item: čerstvá kapusta }
      - { item: koriander }
      - { item: limetka }
---

1. Mleté mäso zmiešame s mrkvou, kapustou, medom, ryžovým octom, sójovou omáčkou, zázvorom, cesnakom a soľou.
2. Zmes roztlačíme na malé placky.
3. Opekáme najskôr stranou s mäsom nadol, keď je takmer hotové, pretočíme na druhú stranu.
4. Podávame s trochou čerstvej mrkvy a kapusty, posypeme koriandrom a zakvapkáme limetkou.
